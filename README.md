# 速攻何切る

最速で聴牌することだけを目的にした、麻雀の何切るiPhoneアプリ。

14枚の手牌から1枚を選んで切る。判定は**点数**で行う。
もっとも速く聴牌できる打牌を100点とし、それに対してどれだけ速いかを点数にする。
**90点以上なら正解**。目先の受け入れ枚数ではないので、受け入れ最大の打牌が
正解にならない局面がある。

打点・役・ドラ・場況・待ちの良し悪しは一切考慮しない。字牌と赤5は使わない。
七対子も考えず、面子手(4面子1雀頭)だけでシャンテン数を数える。

## 構成

- `SokkouCore/` — UIに依存しないロジック層。`swift test` で回せる
- （これから）`Sokkou/` — SwiftUIのアプリ本体

## 記録と称号

最速聴牌（その局のすべての打牌が正解）の累計回数だけで段位が上がる。
割合は使わない。打つほど下がる指標があると気軽に試せなくなるため。

7称号 × Lv10 の70段。61段目（神速雀士 Lv1）で1000回、70段目で10000回。
