## 手順1. App ID を登録する

### なぜ先にやるのか

Xcodeの自動署名は**ワイルドカード**（`A7WA598R44.*`）のApp IDを勝手に作る。
それができてしまうと、手順2でバンドルIDの選択肢が**空になってアプリを登録できない**。
だから明示的なApp IDを先に自分で作っておく。

### 操作

1. https://developer.apple.com/account/resources/identifiers/list を開く
2. 一覧の上にある **⊕**（青い丸にプラス）を押す
3. **App IDs** を選んで Continue
4. **App** を選んで Continue
5. **Description** に `Sokkou Nanikiru` と入力
   - 半角英数のみ。日本語や記号は弾かれる
   - ここは管理用の名前で、App Storeには出ない
6. **Bundle ID** は **Explicit** を選ぶ ← ここが最重要
7. 入力欄に `com.zzzjjj080.Sokkou` を入力
8. **Capabilities は何も触らない**（このアプリは通知もヘルスケアも使わない）
9. Continue → 内容を確認して **Register**

### つまずきやすいところ

- **Explicit を選び忘れると Wildcard になる。** あとから種類は変えられないので、
  間違えたら作り直す（消して作り直しでよい）
- `com.zzzjjj080.Sokkou` は1文字でも違うとやり直しになる。コピペ推奨

## 手順2. App Store Connect にアプリを登録する

**手順1が終わってから。** 先にやると候補が出ない。

1. https://appstoreconnect.apple.com/apps を開く
2. **⊕ → 新規アプリ**
3. 入力する内容

   | 欄 | 入れるもの |
   |---|---|
   | プラットフォーム | iOS |
   | 名前 | `速攻何切る` |
   | プライマリ言語 | 日本語 |
   | バンドルID | `com.zzzjjj080.Sokkou` を一覧から選ぶ |
   | SKU | `sokkou-nanikiru` |
   | ユーザーアクセス | フルアクセス |

4. **作成**

### つまずきやすいところ

- **バンドルIDが候補に出ない** → ページをリロード。手順1の反映に少しかかる。
  それでも出ないなら、手順1で Explicit ではなく Wildcard を選んでいる可能性が高い
- **SKU はあとから変えられない。** ただし App Store には表示されない管理用の文字列なので、
  上の値でなくても困らない
