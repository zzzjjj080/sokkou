# App内課金の審査用スクリーンショット

App Store Connect の課金製品は、**審査用スクリーンショットが1枚無いと
`MISSING_METADATA` のままで提出できない**（引き継ぎ書 11-8）。

## 撮り直し方

    /Users/jin/Claude/Sokkou/store/make-iap-shot.sh

これ1本で、撮影用シミュレータの用意 → 撮影 → 向きの調整まで走る。

## 出るもの

| ファイル | 中身 |
|---|---|
| `coffee-tip.png` | 撮ったまま（**横倒し**。端末は縦のまま、アプリだけ横向きに描かれるため） |
| `coffee-tip-review.png` | 起こしたもの・2622×1206。**人が見て確かめる用** |
| `coffee-tip-upload.png` | **Appleに送る用**・1206×2622（下記の理由で時計回りに回してある） |

## Apple は受け取った画を90度回す（2026-09-02 実測）

**上向きのまま送ると、App Store Connect 側で横倒しになる。**
4回試して分かった向きは次のとおり。

| 送った画 | Apple側に入った画 |
|---|---|
| 上向きの横長 2622×1206 | 横倒しの縦長（**反時計回りに90度**） |
| 上向きの縦長（余白付き） | 横倒しの横長 |
| 反時計回りに回した縦長 | 上下逆さまの横長 |
| **時計回りに回した縦長** | **上向きの横長 ← 正解** |

つまり Apple は必ず反時計回りに90度回す。**先に時計回りへ回して打ち消す。**

寸法は**端末の画面サイズと一致していないと弾かれる**（`IMAGE_INCORRECT_DIMENSIONS`）。
余白を足して好きな大きさにすることはできない。

## 気をつけること

- **価格は `$0.99` と出る。** シミュレータのストアフロントが米国のため。
  `_storefront: "JPN"` を書いても変わらず、`simctl` に変える手段も無い。
  **実機・本番は App Store Connect の ¥200 が出る**（引き継ぎ書 11-9）。
  価格を決め打ちしていない証拠にもなるので、これで問題ない。
- 価格を出すには `.storekit` が要る。`simctl launch` では効かないので、
  スキームを経由する `xcodebuild test` から撮る。
- 投げ銭の行は設定のいちばん下にある。**横向きアプリでは XCUITest の
  `swipeUp()` が画面と噛み合わない**ので、座標を指定して引いている
  （`press(forDuration:thenDragTo:)` なら効く）。
- 撮影は専用シミュレータ `Sokkou-Shot` で行う。他と共有すると、
  別プロジェクトのテストランナーが割り込んで撮影が壊れる（引き継ぎ書 4-59）。

## 登録

**2026-09-02 に登録済み。** 課金製品は `READY_TO_SUBMIT` になった。

やり直すときは API から3手順（引き継ぎ書 11-8）。差し替えは delete してから作り直す。
入ったあとは、`imageAsset.templateUrl` の `{w}x{h}bb.{f}` を埋めて画を取り、
**必ず目で向きを確かめる**（状態が `COMPLETE` でも横倒しで入っていることがある）。
