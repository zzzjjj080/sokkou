# App内課金の審査用スクリーンショット

App Store Connect の課金製品は、**審査用スクリーンショットが1枚無いと
`MISSING_METADATA` のままで提出できない**（引き継ぎ書 11-8）。

## 撮り直し方

    /Users/jin/Claude/Sokkou/store/make-iap-shot.sh

これ1本で、撮影用シミュレータの用意 → 撮影 → 向きの調整まで走る。

## 出るもの

| ファイル | 中身 |
|---|---|
| `coffee-tip.png` | 撮ったまま（**横倒し**。端末は縦のまま、アプリだけ横向きに描かれるため） |
| `coffee-tip-review.png` | **これを登録する。** 起こしたもの・2622×1206 |

## 気をつけること

- **価格は `$0.99` と出る。** シミュレータのストアフロントが米国のため。
  `_storefront: "JPN"` を書いても変わらず、`simctl` に変える手段も無い。
  **実機・本番は App Store Connect の ¥200 が出る**（引き継ぎ書 11-9）。
  価格を決め打ちしていない証拠にもなるので、これで問題ない。
- 価格を出すには `.storekit` が要る。`simctl launch` では効かないので、
  スキームを経由する `xcodebuild test` から撮る。
- 投げ銭の行は設定のいちばん下にある。**横向きアプリでは XCUITest の
  `swipeUp()` が画面と噛み合わない**ので、座標を指定して引いている
  （`press(forDuration:thenDragTo:)` なら効く）。
- 撮影は専用シミュレータ `Sokkou-Shot` で行う。他と共有すると、
  別プロジェクトのテストランナーが割り込んで撮影が壊れる（引き継ぎ書 4-59）。

## 登録

App Store Connect への登録は「口座登録」の側で行う。
